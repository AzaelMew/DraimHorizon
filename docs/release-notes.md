**DraimHorizons 0.21.0** для **Horizon Nightly 2026-11-05 · f319701** (Java 26.3).

**J → Друзья → выбери игрока:**

- **Запрос ТП** (`ТП` в компактном интерфейсе) отправляет `/tpa <ник>`.
- **Обмен** отправляет `/trade <ник>`.

Наведение показывает команду. Сам выбор игрока ничего не отправляет; после нажатия кнопки и отправки меню закрывается. Действия работают для игроков на текущем сервере, даже без relay, в том числе для важных игроков из локальных отметок чата. Перед отправкой повторно проверяются UUID и ник; офлайн-игрокам и себе запросы не уходят. Обычные действия дружбы и авто trust сохранены.

Телепортация требует принятия запроса другим игроком; ограничения и обмен контролирует SMP. Автоматического принятия запросов и подтверждения сделки нет.

После обновления **пересоберите нативные моды** в лаунчере. Совместимость с Horizon прежняя.
