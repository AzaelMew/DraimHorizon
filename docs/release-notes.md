**Claim Borders 0.9.0** для Horizon **c9d474d**.

- **Мои сообщения RU → EN:** русский текст переводится на английский перед отправкой обычным подписанным чатом. Команды остаются без перевода, оригиналы — в истории ввода. Порядок сообщений сохраняется, длинный перевод делится по словам. При ошибке сервиса отправляется оригинал с уведомлением. Переключатель — **M → Чат → Вид / позиция**.
- **Постоянные приваты:** один `/claims` при отсутствии кеша; затем восстановление с диска без запроса при каждом входе. Успешные `/claim` и `/unclaim` обновляют список по подтверждению сервера. До 4096 чанков на владельца.
- **Общий обмен приватами:** все пользователи мода на одном сервере и relay получают списки без добавления в пати и сохраняют их после выхода владельца. Позиции игроков по-прежнему доступны только взаимным друзьям. Relay хранить данные не начал: новый клиент должен хотя бы раз пересечься с владельцем онлайн.
- **Телепортация:** сверху карточки с ником, кнопками принятия/отклонения, секундами и полоской на 60 секунд. Открой чат для клика. Поддерживаются команды `/tpaaccept` / `/tpadeny` и `/tpaccept` / `/tpdeny`; кнопка использует вариант из серверного уведомления. Просроченные и повторные клики не выполняются.
- **Мобы на картах:** цветные отметки загруженных живых существ, режимы все / монстры / выкл., подпись вида и Y при наведении на большой карте. Данные мобов в атлас не записываются.

Для общего обмена обновите участвующие клиенты до **0.9.0**. Relay **1.1.0** совместим, сервер и порты менять не требуется.

После изменения территорий администратором или из другого клиента без мода нужна ручная сверка `/claims`. При смене ключа владельца есть **M → Клеймы → Память → Сбросить кеш приватов игроков**. Имена/UUID в relay не являются подтверждением аккаунта Mojang.

Проверки: 118 Rust-тестов, строгий clippy, перевод обоих направлений через локальный HTTP-провайдер, обмен двух реальных клиентов через relay (включая общий кеш и снятие привата), официальное применение mixins, локальная компиляция Horizon и валидатор `.hnmod`. Интерактивный игровой тест здесь недоступен.
