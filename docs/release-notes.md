**DraimHorizon 0.24.0** for Horizon 6cc93d1 (Java 26.3).

- Translation language screen: independent Input, Output, Chat into and Chat from settings, with 20 common languages and optional source auto-detection. Right click the compact translation button to open it.
- Fix automatic translation of short, mixed and slang messages: unidentified text is sent to the provider instead of silently discarded. Existing language choices and unsent chat drafts are preserved.
- One-line minimap X/Y/Z strip; editable coordinates in the X waypoint editor.
- Friends chat includes regular messages from friends and important players.
- Compact + / minus presence events, centered language control and top settings tabs.
- Experiments confirmation with a red outline, Lucide warning/check icons and soft green/red actions.
- Auto reconnect defaults on, with a saved toggle, cancelable countdown and five backed-off attempts. Manual exit and permanent access refusals stop retries.
- Relay 1.3.0 archive included. Shared DeepL fallback for targets beyond RU/EN requires relay 1.3.0; Google supports the new targets directly.

The current launcher still displays the stable `claim_borders` bundle ID for GitHub native mods; the separate launcher display-name patch is included in the repository.
