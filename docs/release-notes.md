**DraimHorizons 0.12.0** для Horizon **f42ef42**.

- Совместимость закреплена за `f42ef42ef6ceccb3c6a20bea2481d87949a51c81`; контрольные суммы затрагиваемых исходников пересчитаны по этому commit.
- Для сборки закреплён horizon-mixins `10fdf8bda39d1e336c0f13f802db1041fbe41abf` с публичным исправлением из [PR #25](https://github.com/horizon-rust/horizon-mixins/pull/25). Исправление ещё не слито в основную ветку инструмента: оно разрешает встроенный атрибут Rust `recursion_limit`, из-за которого прежний инструмент отказывался применять любые хуки к новой версии Horizon. Commit доступен в каноническом репозитории и проверяется отдельно.
- Код карты, торговли, чата, TPS и обмена приватами сохранён; внутренний ID и формат пользовательских настроек не менялись. Relay 1.1.0 совместим.
- Добавлена изолированная сборочная проверка в GitHub Actions для ветки `feature/horizon-f42ef42`. Она выполняет Rust-тесты, clippy, официальное стадирование, тесты исправленного индексатора, компиляцию реального клиента и проверку архива. Локальные изменения Horizon и скрытые патчи инструмента не применяются.

Игровой визуальный тест недоступен. Используется точный source/tool pin; сборка на иной ревизии Horizon требует отдельной проверки.

Проверки: 145 Rust-тестов мода, строгий clippy, проверки relay, регрессионные тесты индексатора, полная компиляция клиента без предупреждений и штатный валидатор `.hnmod` прошли в GitHub Actions.
