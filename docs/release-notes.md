**DraimHorizon 0.29.5 - Baritone bridge, mining grid, schematic picker (unreleased)**

Target: official Horizon Nightly source `fdc87aecdbd116bf1e08adcd062fcbaea8c2e2ca`.

- With the separate [horizon-baritone](https://github.com/luhnox/horizon-baritone) mod installed and on, Navigation, Mining, Tunnel (without Floor), Farm and unrotated Schematics run on real Baritone (`goto`, `goal`, `follow player`, `mine`, `tunnel`, `farm`, `build`); the action keys send `pause`, `resume` and `cancel`. Without it the built-in drivers run as before, and nothing is ever sent to the server.
- Mining targets are a grid of toggles, like the map's structure filters; several can be mined at once.
- The schematic file button opens the folder when it is empty and a file list otherwise.
- Farm sowing aims at the real 15/16-high farmland top.
- Drain fills deep water by dropping sand or gravel into the surface cell.

Not verified in game. No installation or publication is implied.
