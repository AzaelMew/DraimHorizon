**DraimHorizon 0.24.1** for Horizon 821426b (Java 26.3).

- The launcher now lists the mod as `draimhorizon` instead of `claim_borders`. Horizon IDs are lowercase-only, so `DraimHorizon` cannot be the ID itself.
- Saved settings and data keep their previous `claim_borders` storage key.
- Custom key bindings and the launcher on/off state reset once because the launcher stores them by mod ID.
