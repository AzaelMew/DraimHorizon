**Claim Borders 0.3.0 — меню управления и границы в пещерах** для Horizon **c9d474d**.

После входа в мир нажми **M**. Откроется меню с вкладками:

- **Waypoints** — создать метку в текущей позиции, изменить название/цвет и удалить её.
- **Party** — пригласить, принять приглашение, удалить друга, обновить приваты и включить обмен данными.
- **Claim Borders** — видимость своих и дружеских границ, цвета, прозрачность, дальность и вертикальный охват.

По умолчанию границы видны сквозь блоки полупрозрачной сеткой ±32 блока вокруг игрока — удобно в пещерах. Обычный depth-tested режим можно вернуть. Параметры сохраняются. Клавиша меню переназначается в Options → Mods → Claim Borders; там есть кнопка открытия меню. Команды остаются доступными.

**Обновления в лаунчере:** установи мод через Install from GitHub по ссылке `https://github.com/DraimCiDo/DraimHorizon`, чтобы лаунчер сохранил origin и проверял новые теги. Этот релиз имеет тег `v0.3.0`, а версия `.hnmod` — `0.3.0`. Замените предыдущую версию, не устанавливайте два bundle `claim_borders` одновременно.

Пати по-прежнему требует мод у обоих игроков. Обмен идёт через видимые серверу `/msg`; подписанный режим требует подтверждения пользователя. Все возможности 0.2.0 сохранены.

Совместимость: Horizon `c9d474dd9116e84c243f8992d75c11314df56f06`. Пакет содержит исходники и собирается лаунчером в клиент. Пройдены тесты моделей, clippy, mixin plan/apply, проверка компиляции клиента и валидатор пакета. Интерактивный игровой тест в этой среде недоступен.
