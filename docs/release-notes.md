**DraimHorizon 0.38.0 - A storage for mining**

Target: official Horizon Nightly source `fdc87aecdbd116bf1e08adcd062fcbaea8c2e2ca`.

- Set a storage container in the Mining tab. When the inventory is full the miner walks there, unloads everything it does not need (it keeps tools, food, a totem and one stack of the mined block), walks back and goes on.
- If the container is full or unreachable the miner idles and tries again later.
- Builds on 0.37.13: walking down drops, mining what is in reach.

Not verified in game. No installation or publication is implied.
