**Claim Borders 0.4.0** для Horizon **c9d474d**.

- Party передаёт данные через отдельный WebSocket relay с шифрованием между клиентами. `/msg` больше не используется.
- Меню **M → Party**: настройка URL/токена, подключение, копирование своего кода, взаимное приглашение по коду друга.
- Метки друзей и waypoints уменьшены и сохраняют фиксированный экранный размер при удалении; плавное затухание сохранено.
- Отдельный архив **claim_borders-relay-0.4.0.tar.gz** содержит сервис, Docker Compose/Caddy и инструкцию для развёртывания на своём хосте. Публичный relay не развёрнут.

Разверни relay по `relay/README.md`, затем у обоих игроков задай `wss://твой-домен/v1/relay`. Обменяйтесь кодами через доверенный канал, пригласите и подтвердите дружбу. После перехода с 0.3.0 друзей нужно добавить заново; waypoints и настройки границ сохраняются. UUID/ник в сертификате не являются проверкой владения игровым аккаунтом.

Для обновлений лаунчера используй Install from GitHub: `https://github.com/DraimCiDo/DraimHorizon`. Тег **v0.4.0**, версия пакета **0.4.0**. Замени предыдущий bundle, не устанавливай две версии одновременно.

Проверки: тесты моделей и криптографии, обмен двух Rust-клиентов через реальный Python relay, серверные интеграционные тесты, healthcheck контейнера под непривилегированным пользователем, clippy и компиляция нативного клиента с официальными mixins. Игровую отрисовку и публичный TLS на пользовательском хосте здесь проверить нельзя.
