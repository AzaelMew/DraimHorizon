Первый релиз **Claim Borders** для Horizon **c9d474d**.

Установи `claim_borders-0.1.0.hnmod` в `horizon-native-mods/` экземпляра игры, собери нативные моды через лаунчер и выполни на сервере `/claims`.

- Зелёная рамка показывает внешний контур твоих приватов; у соседних чанков нет внутренней стенки.
- `/claimborders` переключает видимость; `/claimborders refresh` один раз запрашивает `/claims`.
- После `/claim` / `/unclaim` выполни `/claims` повторно.
- Только собственные приваты, только формат ответа Horizon SMP. Серверный мод менять не требуется.
- Рамка следует по высоте за игроком и видна в радиусе 160 блоков; через блоки не рисуется. F1 скрывает её.

Совместимость закреплена на `c9d474dd9116e84c243f8992d75c11314df56f06`. `.hnmod` — исходный Rust-bundle, который лаунчер компилирует в клиент; это не готовый исполняемый файл.

Перед публикацией workflow проверяет Rust-тесты, форматирование, clippy, официальный mixin plan/apply, компиляцию настоящего клиента (`cargo check` без аудио/контроллеров) и архив штатным валидатором Horizon. Интерактивный запуск с аккаунтом игрока и ресурсами Minecraft не выполнялся; сочетания с другими нативными модами не проверены.

Рядом с пакетом опубликована контрольная сумма SHA-256. В каталоге Horizon мод пока не зарегистрирован.
